# Country Stats

A dashboard of statistics about countries, built for phones and desktops, on data from [Our World in Data](https://ourworldindata.org) (CC BY 4.0).

This repository used to hold a medical-imaging ML project (`rls-med`). That code is kept, untouched, in [`archive/rls-med/`](archive/rls-med/).

## Pages

Also hosted as private Claude artifacts: [world overview](https://claude.ai/artifact/X28oUf5M5WVU9rVfk6Xgor) · [component kit](https://claude.ai/artifact/BEYCNDpcxb7Lm9tfVPYcSY).

| Page | What it is |
|---|---|
| `dashboard/index.html` | **World overview.** One filter row (indicator + regions) drives a map, top-10 ranking, regional trends, distributions, income vs. life expectancy, change since 2000 and a sortable table. |
| `dashboard/components.html` | **Component kit.** Every chart type with lettered options (A/B/C…), so we can refer to them as e.g. “Maps C”. |

Theme: **Meridian** (light + dark). The three other directions from the look book are in git history (commit `a60a48a`).

## Data

```sh
npm ci
npm run data                      # download from OWID, cache CSVs in data/owid-raw/, build dashboard/data/owid.js
npm run data -- --offline DIR     # rebuild from cached CSVs
```

`scripts/fetch-owid.mjs` pulls these OWID grapher charts (CSV + metadata):

| Key | OWID chart | Notes |
|---|---|---|
| `life` | `life-expectancy` | years at birth |
| `gdp` | `gdp-per-capita-worldbank` | constant international-$ at PPP |
| `co2` | `co-emissions-per-capita` | tonnes per person |
| `net` | `share-of-individuals-using-the-internet` | % of population |
| `pop` | `population` | people |
| region | `continents-according-to-our-world-in-data` | North + South America merged into “Americas” |

Rules: years from 2000; countries under 1 million people are left out (`MIN_POP`); a country's “latest” value is its most recent year, if no more than 3 years old. Every page credits OWID and each underlying source.

The cloud environment needs `ourworldindata.org` on its network allowlist to run `npm run data`.

## Run locally

```sh
npm run dev        # http://localhost:5173/
```

Pages are HTML fragments (no `<html>`/`<head>`) so the same files publish as Claude artifacts; the dev server wraps them.

## Layout

```
dashboard/
  index.html, components.html   pages
  themes.mjs                     theme tokens (edit here, then npm run themes)
  css/themes.css                 generated
  css/base.css                   layout + component styles, tokens only
  js/core.js                     light/dark, tooltip, responsive mount, formatting, gap-safe helpers
  js/charts.js                   D3 charts: rankedBars, distribution, lineChart, scatter,
                                 worldMap (choropleth / binned / tiles / bubbles), change, heatmap
  js/ui.js                       stat tiles, filter controls, sortable table, profile card
  data/owid.js                   generated by npm run data
  data/world-110m.js             Natural Earth 110m countries (world-atlas 2.0.2)
scripts/
  fetch-owid.mjs                 OWID download + build
  build-themes.mjs               tokens -> CSS
  serve.mjs                      dev server
```

Libraries: D3 7.9.0 and topojson-client 3.1.0 from CDN in the browser; no build step for the pages.

## Design rules

- Region colors are a fixed five-slot palette, checked for colorblind separation and contrast in light and dark. Colors follow the region, never its rank.
- Every chart has hover/tap readouts with hit areas larger than the marks; text never takes a series color.
- One filter row scopes everything below it.
- Missing years and countries are drawn as gaps or “No data”, never filled in.
